API

このダッシュボードは/api/v1/statusのJSONだけを使っています。同じ値を自由に取得できます。

$ curl https://nercone.dev/api/v1/status

単位

値単位
容量・通信量・I/O量ビット (バイトの8倍)
リンク速度ビット毎秒
使用率0.0 〜 1.0
周波数GHz
温度°C
メモリの速度MT/s

このサーバーで取得できない値はnullになります。CPU使用率の計測のため、応答には約0.25秒かかり、結果は1秒間キャッシュされます。通信速度や読み書きの速度はAPIに含まれず、このダッシュボードが前回の値との差から計算しています。ストレージのio.deviceは、読み書きの量を計測したディスクの名前です。同じディスク上の複数のストレージが、同じ値を共有することがあります。

ストレージの使用量

キー意味
usage.totalファイルシステムが使える領域の大きさ。APFSでは、ボリュームが共有するコンテナの大きさ
usage.availableプログラムがまだ書き込める量。macOSでは、容量が必要になるとOSが削除する解放可能な領域(キャッシュやローカルスナップショットなど)を含み、Finderの「利用可能」と同じ値
usage.used使用中の量。macOSではtotal - available(Finderの「使用済み」と同じ)、それ以外では割り当て済みのブロック
usage.freeまったく割り当てられていない量
usage.consumedこのファイルシステム自体が使っている量。APFSでは、コンテナのうちこのボリュームの分だけ
