Progress

Linear, Circular, and Logo progress indicators.

Shows how much of a task is done. progress.js reads the value from aria-valuenow, within aria-valuemin (default 0) and aria-valuemax (default 100), and sets --progress-value (from 0 to 1) on the element. Without aria-valuenow, the progress is indeterminate.

Set --progress-value in the style attribute as well, so the progress is drawn without JavaScript. progress.js replaces it when aria-valuenow changes.

Linear

Circular and logo

Range

aria-valuemin="0" aria-valuemax="5" aria-valuenow="3" is 60%.

Customization

Change the size with --progress-size (default 48px) and --progress-thickness (default 4px), the indeterminate animation with --progress-duration, and the colors with --color-progress and --color-progress-track.

Usage

<div class="progress-linear" role="progressbar" aria-label="Upload" aria-valuenow="40" style="--progress-value: 0.4"></div>

<svg class="progress-circular" viewBox="0 0 48 48" role="progressbar" aria-label="Upload" aria-valuenow="40" style="--progress-value: 0.4">
    <circle class="progress-track"     cx="24" cy="24" r="20" pathLength="1"/>
    <circle class="progress-indicator" cx="24" cy="24" r="20" pathLength="1"/>
</svg>
