Typography

Text elements need no classes. font.css defines the fonts and the font utility classes.

Font families

Each family is a variable and a class of the same name. The Nercone fonts are variable fonts that cover Latin and CJK; they are loaded from assets.nercone.dev unless they are installed. The families after them are fallbacks.

Variable and classFirst fontFallbacks

--font-family-serifNercone Serif CJKCharter, Noto Serif JP/SC/TC/KR, serif
--font-family-monoNercone Mono CJKMeslo, Noto Sans JP/SC/TC/KR, monospace
--font-family-sans-nfNercone Sans CJK NFSame as sans
--font-family-serif-nfNercone Serif CJK NFSame as serif
--font-family-mono-nfNercone Mono CJK NFSame as mono

The page uses sans. <code> and <pre> use mono-nf. The -nf families include the Nerd Fonts icons.

Text

Bold (b), strong, italic (i), emphasis (em), underline (u), strikethrough (s), link (a), code, Ctrl + C (kbd), highlight (mark), small, H2O (sub), x2 (sup), HTML (abbr).

Links keep the color of the text around them and are underlined. <strong> is bold in --color-foreground-alt, so it stands out more than <b>. <mark> is --color-mark-foreground on --color-mark-background: yellow-bright (yellow-40 in the light themes) on yellow-opacity-10, or black on jis-yellow in the UD themes.

Code

<pre> has a border and scrolls horizontally when its content is too wide. Inline <code> breaks inside a word when the word does not fit on a line.

(() => {
    const toast = window.nercone.get('toast');
    document.querySelector('form').addEventListener('submit', () => toast.show('Saved', { variant: 'success' }));
})();

Font sizes

The classes use the keywords of CSS, so they follow the font size set by the user.

Relative to the parent: font-size-smaller and font-size-larger.

Style and decoration

font-style-italic, font-style-normal on <i>, font-decoration-underline, font-decoration-overline, font-decoration-line-through, and font-decoration-none on <a>.

Each group also has classes that reset it: font-variant-normal, font-variant-caps-normal, font-variant-ligatures-normal, font-variant-numeric-normal, and font-variant-position-normal. The ligature groups can be turned off one by one with font-variant-ligatures-no-common, -no-discretionary, -no-historical, and turned back on with -contextual.
