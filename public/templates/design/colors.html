Colors

Every color is a custom property. The palette is in color.css; the colors by purpose come from the theme.

Hover a swatch to see its variable name. Click it to copy the color; the control above each panel chooses the format. The swatches show the colors of the current theme.

Base colors

Every palette starts from one of these. The hues are hwb() colors with a whiteness of 20% and no blackness; only the angle differs.

{%- for hue in hues %} {%- endfor %}
VariableValue
--color-blackhwb(0 0% 100%)
--color-whitehwb(0 100% 0%)
--color-greyhwb(0 50% 50%)
--color-{{ hue }}hwb({{ hue_values[hue] }} 20% 0%)
--color-starkSet by the theme: --color-white in dark themes, --color-black in light themes

stark is the color with the most contrast against the background. Use it for things that should stand out the most, such as the logo on the loading overlay and the tint of the hero.

Palette

Each palette has 41 steps in increments of 5. From 0 to 100, the base color is mixed with black: 0 is black and 100 is the base color. From 100 to 200, it is mixed with white: 200 is white. Refer to a step as --color-{name}-{step}.

{%- set steps = range(0, 201, 5) | list %}
{{ format_control("palette") }} {{ palette(["grey"] + hues + ["stark"], steps) }}

Because stark is already white in dark themes and black in light themes, half of its steps are the same color: stark-100 to stark-200 are all white in dark themes, and stark-0 to stark-100 are all black in light themes.

Brightness

Frequently used steps have names. For the hues, -dark is step 45, -normal is 75, and -bright is 100. For grey, whose base color is already a middle grey, they are 25, 50, and 75.

{{ format_control("brightness") }}
{%- for family in ["grey"] + hues %} {%- for name in ["dark", "normal", "bright"] %} {{ swatch("--color-" ~ family ~ "-" ~ name, family ~ "-" ~ name) }} {%- endfor %} {%- endfor %}

The components use -bright for text and -normal for borders, as in the status buttons and the alert blocks.

Opacity

--color-{name}-opacity-{step} is the base color mixed with transparent: 0 is transparent and 100 is the base color. There are 21 steps in increments of 5. Besides the palettes, black and white have them as well.

{%- set opacity_steps = range(0, 101, 5) | list %}
{{ format_control("opacity") }}
{%- for family in ["black", "white", "grey"] + hues + ["stark"] %}
{{ family }}
{%- for step in opacity_steps %} {{ swatch("--color-" ~ family ~ "-opacity-" ~ step, step, compact=true) }} {%- endfor %}
{%- endfor %}

Translucent colors take on the color of what is behind them, so they work on any background. The themes use white-opacity-* and black-opacity-* for text, layers, and borders.

JIS safety colors

--color-jis-{name} are the safety colors of JIS Z 9103:2018, in sRGB. Their meaning depends on their exact color, so they have no palette, brightness, or opacity steps; use them as they are. The UD themes use them for the status colors.

{{ format_control("jis") }}
{%- for name in jis %} {{ swatch("--color-jis-" ~ name, "jis-" ~ name) }} {%- endfor %}

Each component also has its own colors, --color-{component}-*, such as --color-button-primary-background and --color-toast-error-border. They refer to the colors above, so most pages never need to change them. They are listed on the page of each component.

Utility classes

Classes set the text color (fg-color- or text-color-), the background color (bg-color- or background-color-), and the border color (bd-color- or border-color-) to a color. They are declared with !important.

Overriding colors

The variables can be set on any element, and the new value applies to that element and its descendants. Change the colors by purpose or the component colors, not the palette, so that the change follows the theme.

.pink {
    --color-button-primary-background: var(--color-pink-bright);
    --color-button-primary-border:     var(--color-pink-bright);
    --color-slider:                    var(--color-pink-bright);
    --color-slider-thumb:              var(--color-pink-bright);
}

Swatch

The swatches on this page are a component. swatch shows --swatch-color above its content, over a checkerboard that shows transparency. swatch-compact is smaller and centered.

div.swatch

With swatch.js, clicking an element with data-swatch="--color-…" copies that color and shows a toast. The nearest data-swatch-format on it or an ancestor chooses the format: variable (var(--color-…), the default), rgb, or hex. rgb and hex are computed in sRGB from the element, so they follow the theme; colors outside sRGB cannot be copied as them.

.sky { --swatch-color: var(--color-sky-bright); }

<div data-swatch-format="hex">
    <button class="swatch sky" type="button" data-swatch="--color-sky-bright"><span>sky-bright</span></button>
</div>
const swatch = window.nercone.get('swatch');
await swatch.copy(element);        // true when copied
await swatch.copy(element, 'rgb'); // in another format

Change the height of the color with --swatch-height (default 48px), the padding of the content with --swatch-padding (default 4px 8px), the size of the checkerboard with --swatch-checker-size (default 12px), and the colors with --color-swatch-*. The options of swatch.js are on Scripts.
